# DSA Smart Expense Manager

**Developed by Vikas Yadav**

A responsive browser-based expense manager designed as a BTech/placement portfolio project. It demonstrates practical Data Structures and Algorithms concepts while providing a useful personal finance dashboard.

## Features
- Add income and expenses
- Categories and descriptions
- Monthly budget tracking
- Balance, income and expense summary
- Search and type filtering
- Amount sorting
- Delete individual transactions
- Clear all data
- LocalStorage persistence
- Responsive mobile-friendly UI
- Highest-spending category insight
## DEMO
https://yadavvikas06081302.github.io/DSA-Smart-Expense-manager/

## DSA Concepts
1. **Array/List** — stores transaction records.
2. **HashMap/Object** — aggregates spending by category.
3. **Linear Search** — searches descriptions/categories.
4. **Filtering** — separates income and expenses.
5. **Comparison Sorting** — sorts transactions by amount.
6. **Aggregation** — calculates total income, expenses and balance.

## How to Run
No installation is required.

1. Download/extract the ZIP.
2. Open `index.html` in Chrome.
3. Start adding transactions.

For GitHub Pages:
1. Create a GitHub repository, e.g. `DSA-Smart-Expense-Manager`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → / (root)**.
5. Save and open the generated Pages URL.
